# 🐾 Pet Store API Automation

## 📌 Project Overview

Pet Store API Automation is a Python-based API automation testing project designed to test and validate the Pet Store API. This repository contains automated test scripts, utilities, and configuration files for comprehensive API testing.

## 📁 Key Directories

### /tests

Contains all automated test cases for the Pet Store API.
Test files are organized to cover various API endpoints and functionalities such as:

* Create (POST)
* Read (GET)
* Update (PUT)
* Delete (DELETE)

### /utils

Houses reusable utility functions and helper modules used across the test suite:

* API request handling
* Response validation
* Common helper functions
* Configuration utilities

## 🚀 Getting Started

### 🔹 Prerequisites

* Python 3.x
* pip (Python package manager)

### 🔹 Installation

1. Clone the repository:

```
git clone <repository-url>
cd Pet-store-api-automation
```

2. Install dependencies:

```
pip install -r requirements.txt
```

---

## ▶️ Running Tests

Run test cases using your preferred test runner.

### Using pytest

```
pytest -v
```

### Generate HTML Report

```
pytest -v --html=report.html
```
